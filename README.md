# gestion-operarios

**Planning de Equipo**: app web para repartir a los operarios en los puestos cada día, con bajas, asuntos propios, reglas de reparto y envío por WhatsApp.

Todo está en un solo archivo, `index.html`. Para usarla, ábrelo en el navegador o publícalo con GitHub Pages (Settings → Pages → rama `main`). Los datos se guardan en el propio navegador.
